# pcsx2x6-libretro

A project to bring PCSX2x6's NAMCO System 246 and System 256 arcade emulation to libretro frontends such as RetroArch.

## Status

The project is in the research and planning stage. No emulator source code or working libretro core is included yet, and there is currently no build or run target.

See the [development roadmap](docs/roadmap.md) and [baseline definition](docs/baseline.md).

## Upstream projects

- [PCSX2](https://github.com/PCSX2/pcsx2): the upstream PlayStation 2 emulator.
- [PCSX2x6](https://github.com/PS2Homebrew-arcade/pcsx2x6): the source of System 246 and System 256 arcade support.
- [PCEE2](https://github.com/WizzardSK/pcee2-libretro) and [paraLLEl-PS2](https://github.com/libretro/parallel-ps2): references for libretro integration.
